# Product Roadmap — NorthBridge One

> [!NOTE]
> Based on secondary research and simulated stakeholder discovery. No real interviews were conducted. This is a portfolio prototype.

## Phase 1: Unified Context + Attention (The MVP - Current Focus)
**Goal:** Establish the foundational data architecture, create the unified Student 360 view, and introduce basic attention signals to solve the core problem of information fragmentation.

| Features | Value Delivered | Dependencies | Estimated Effort |
| :--- | :--- | :--- | :--- |
| Core Data Integrations (SIS, LMS) | Breaks down data silos to populate the platform. | API access to legacy systems | High |
| Role-Based Dashboards | Provides relevant entry points for different users. | User authentication setup | Medium |
| Student 360 Profile | Gives a single, holistic view of a student. | Data Integration | High |
| Basic Attention Signals | Proactively alerts staff to simple anomalies. | Notification Engine | Medium |
| Intervention Logging & Action Center | Creates accountability for follow-ups. | None | Medium |
| Basic Parent App (Web) | Connects parents to the unified data. | Responsive UI framework | Medium |

## Phase 2: Operational Workflows (Next 6 Months)
**Goal:** Expand beyond student-centric data to streamline complex operational processes for administrative and leadership staff.

| Features | Value Delivered | Dependencies | Estimated Effort |
| :--- | :--- | :--- | :--- |
| Advanced Attendance & Leave Management | Streamlines staff absence tracking and substitute allocation. | Phase 1 Admin Dashboard | High |
| Resource Booking System | Manages room and equipment reservations centrally. | None | Medium |
| Extracurricular Activities (ECA) Module | Manages sign-ups, attendance, and billing for clubs. | Phase 1 Parent App | High |
| Form Builder & Approvals | Digitizes permission slips, expense claims, etc. | None | Medium |
| Advanced Cohort Reporting | Allows leadership to generate custom compliance reports. | Phase 1 Data Architecture | Medium |

## Phase 3: Advanced Analytics (Year 2)
**Goal:** Leverage accumulated data to provide deeper insights, trend analysis, and better strategic decision-making capabilities.

| Features | Value Delivered | Dependencies | Estimated Effort |
| :--- | :--- | :--- | :--- |
| Trend Analysis Dashboards | Visualizes long-term academic and attendance trends. | Sufficient historical data | High |
| Cohort Comparison Tools | Allows tracking performance across different years/groups. | Phase 2 Reporting | Medium |
| Custom Report Builder (Self-Service) | Empowers users to build their own data visualizations. | Analytics infrastructure | High |
| Wellness Pulse Surveys | Integrates quick student wellbeing checks into daily workflows. | Phase 1 Core App | Medium |
| Financial Health Dashboard | Connects enrollment data to high-level revenue forecasting. | Integration with Finance system | High |

## Phase 4: Intelligent Capabilities (Future Vision)
**Goal:** Move from reactive alerting to proactive prediction using advanced modeling and AI to support educators.

| Features | Value Delivered | Dependencies | Estimated Effort |
| :--- | :--- | :--- | :--- |
| Predictive Risk Modeling | Identifies students at risk of failing/dropping out *before* obvious signals appear. | Large datasets, ML infrastructure | Very High |
| AI-Assisted Report Generation | Drafts initial narrative reports based on data points to save teacher time. | LLM integration, Privacy compliance | High |
| Automated Schedule Optimization | Generates complex school timetables automatically resolving conflicts. | Phase 2 Workflows | Very High |
| Smart Intervention Recommendations | Suggests successful interventions based on historical similarities. | Phase 1 Intervention data | High |
